Checking non-comparable types and nil values

At the moment our Equal() function is nice and simple, but it has a couple of limitations.

Firstly, not all types in Go can be compared using the comparison operator !=. Specifically, slices, maps, and functions (or any struct types containing those things) are non-comparable, meaning that our Equal() function will not work for those types.

To get around this limitation, we should change the Equal() function to check for equality by using reflect.DeepEqual() instead of the != operator.

Secondly, there is a subtle and non-obvious problem if we want to check whether something equals nil or not. In Go, there may be times where an interface holds a nil value, but the interface itself does not equal nil — either when compared using the comparison operators or reflect.DeepEqual(). To get around this, we will need to write an isNil() helper function that uses the reflect package to determine whether the concrete value stored in the interface is nil or not.
